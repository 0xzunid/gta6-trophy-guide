Leonida Trophy Atlas — an offline guide and tracker for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 Platinum, 2 Gold, 6 Silver, 46 Bronze; 28 hidden until earned). Every trophy has its official name, description and grade plus a guide written for this atlas, in our own words, citing its source. Includes a checklist with progress saved in localStorage (export/import), filters by kind and grade, search, a spoiler setting that hides story trophies until earned, a 7-stage platinum roadmap (~200 hours, one playthrough, all offline), and the one possibly missable trophy — Positive Mental Attitude — flagged throughout.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide is plain static files under `app/` and works with the network off.
